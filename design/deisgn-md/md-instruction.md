# Website-to-Design.md Method

1. **Inspect the source:** Read the requested page and relevant linked pages. Review HTML and site-specific CSS when available; use them to verify typography, colors, spacing, responsive rules, components, and image behavior.
2. **Separate evidence from inference:** Record directly observed values and patterns. Mark inferred or unavailable details as estimates; do not present generic recommendations as measured facts.
3. **Map the experience:** Summarize brand atmosphere, page/section rhythm, navigation, content hierarchy, photography, interactions, and responsive behavior.
4. **Extract the system:** Organize findings into a practical design spec: visual theme, palette and roles, typography, components, layout/spacing, depth, do/don't guidance, responsive behavior, and concise implementation prompts.
5. **Be specific and reusable:** Include hex values, font families, sizes, weights, radii, spacing, shadows, breakpoints, and named component states when source evidence supports them. Give each token a role and usage rule.
6. **Capture distinctive patterns:** Document signature sections, cards, image crops/overlays, navigation, calls to action, carousels, location/contact blocks, and footer.
7. **Keep fidelity:** Preserve the source site's real content and visual character. Do not impose another brand palette or invent unsupported features.
8. **Check the result:** Ensure the document is internally consistent, responsive guidance matches the source, and quick-reference values agree with the detailed sections.
